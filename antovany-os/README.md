# Antovany OS — GitHub Knowledge Layer

Antovany OS is a lifetime Second Brain and personal Knowledge Base Management System (KBMS) designed to turn complexity into clarity, then clarity into action.

This GitHub layer is intentionally **public-safe** and version-controlled. It contains reusable frameworks, schemas, AI handoff protocols, decision methods, and publishable knowledge assets. It is **not** the canonical storage location for confidential evidence, personal records, legal documents, financial information, credentials, or private journals.

## Role in the Antovany ecosystem

- **Antovany OS** — private/semi-public intelligence and knowledge engine
- **Google Drive / Docs** — canonical evidence and durable source documents
- **Notion** — living workspace, dashboards, PARA execution, and linked knowledge
- **GitHub** — version-controlled frameworks, schemas, skills, machine-readable knowledge, and code-ready assets
- **antovany.com / CEO Decision Lab** — public authority and publishing layer
- **Brainy Lab** — interactive reasoning and simulation layer

The intended flywheel is:

`Think → Capture → Validate → Structure → Decide → Publish → Interact → Learn → Update`

## Operating principles

1. PARA + CODE for organization and knowledge flow.
2. One source of truth for every canonical fact or document.
3. Progressive summarization rather than uncontrolled duplication.
4. Explicit decision rights and traceable assumptions.
5. Time-sensitive knowledge always carries an `as_of` date.
6. Claims are tagged as `VERIFIED`, `SUPPORTED`, `HYPOTHESIS`, `NEEDS_VALIDATION`, or `TIME_SENSITIVE`.
7. Public GitHub content must pass a privacy and reputational-risk filter before publication.

## Public-safe boundary

Never commit secrets, passwords, access tokens, government IDs, private addresses, confidential employment/legal documents, unpublished sensitive negotiations, or personally identifying third-party information.

For material that is useful to AI but not safe for publication, store only a pointer, abstract, non-sensitive metadata, or a redacted derivative here. The canonical source remains in the appropriate private system.
